# Chrome Dinosaur Game Clone

A browser-based recreation of the famous Chrome dinosaur game that appears when you're offline.

## How to Play

1. Open `index.html` in your web browser.
2. Press Spacebar, W, or Up Arrow to make the dinosaur jump.
3. Avoid obstacles (cactuses and birds) for as long as possible.
4. Your score increases the longer you survive.
5. When you crash, press Enter or Spacebar to restart.

## Game Features

- Dinosaur that can jump over obstacles
- Randomly generated cactuses and birds
- Score tracking with high score saved in local storage
- Increasing difficulty as your score gets higher
- Decorative clouds in the background
- Mobile support with touch controls

## Technical Details

This game is built using vanilla HTML, CSS, and JavaScript. The assets are embedded as base64 data URLs to keep everything in a few simple files without external dependencies.
